# Provenance: the first real boot, 3 October 2026

This folder holds one video and the evidence that it is the same video that was already stored on GitHub, in the author's private repository, on 3 October 2026.

## What the video is

An 8.3-second phone recording of the laptop screen during the first boot of the AWIG-OS kernel from a USB stick on the author's own laptop, on 3 October 2026. It shows the kernel's output scrolling and the boot ending in a halt. It is published unedited, exactly as shot. The file is `first-real-boot-2026-10-03.mov`.

## What is published and what is not

Published: the video (byte for byte), this note, the checksum file `SHA256SUMS`, and an excerpt of GitHub's push record. The excerpt leaves out the previous commit's hash and the account's profile and avatar links.

Not published: the private repository, its source, its history, any other file from the original commit, and the original commit itself. Pushing that commit would publish everything behind it, so only the video's bytes are copied.

## How to check it

```
sha256sum -c SHA256SUMS                                  # the public file matches the listed hash
git hash-object first-real-boot-2026-10-03.mov           # prints e9fc485a43ac13d06afa2a915a9d7e8c171ea00f
```

The second line prints the same git object id that the private repository recorded for the file on 3 October.

## What a stranger can and cannot verify

A stranger can verify that this public file has the SHA-256 and the git object id written here. A stranger cannot read the private repository, so they cannot fetch the 3 October push record themselves. The original commit is not signed, so GitHub's record ties the push to the author's account but the commit itself carries no signature. The author can show the full record and the original commit to a verifier by giving read access to the private repository or by sharing a screen, and GitHub's own records of the push stand as the server-side source.

The video's embedded metadata includes the phone model and the location where it was shot, left in place deliberately so that the published file is identical to the stored one.
