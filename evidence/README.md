# Evidence

Dated records that something happened, kept apart from the code and the design papers.

Each record is one folder named `YYYY-MM-DD-what-happened/`. It holds the artefact itself, unchanged, a `SHA256SUMS` file, and a `PROVENANCE.md` that says where the artefact came from, which clock says what, and what a stranger can and cannot check. A record is added in a normal commit with its real date. Nothing here is backdated: the date of the thing and the date of publication are both written down.
