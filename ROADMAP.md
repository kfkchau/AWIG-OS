# Roadmap

What is being built now, and what comes next, in order. No dates: a thing appears in the code folder when it can be checked, and nothing is promised by a calendar. The status page says what is true today; this page says what is being worked toward.

Being built now, in two parallel lines:

**Actors.** Every program, human login, AI session or driver becomes an actor by one recorded act: its identity sealed, its rule set fixed at birth, its permission the intersection of what it declared, what its invoker holds, and what the rules of the place allow. Refusals recorded like decisions.

**The installer.** One file, written to a USB stick, that boots an ordinary machine into the kernel, probes the hardware, writes what it found to the stick's own record, and touches no disk. Installing onto a disk is a later, deliberate act with the owner present. The same line of work carries the speed pass: the kernel's memory serving and disk reading tuned piece by piece, each change behind the existing tests, the numbers re-published with the image.

Next, in order, each started only when the work before it closes:

1. A real organisation living on the system end to end: its constitution loaded as rows, every seat an actor in its own box.
2. A shared working environment: several people and AI actors acting on one record at the same time, every act attributed, instead of separate sessions side by side.
3. Scale and time: very large records, old rows readable years later, keys rotating, records outliving their machines.
4. Reach: separate records joining by signed handshake, and entry versions of the system that run inside other operating systems, on desktops and phones, each a different performer beneath the same seam, so the meaning of an act does not change with the host.

Further out, designed on paper, not scheduled: recovery of a working system from any surviving fragment of its record, and many-to-many hosting of organisations. The theory these steps implement is in [`ARCHITECTURE.md`](./ARCHITECTURE.md); what you can run today is in [`STATUS.md`](./STATUS.md).

To follow the work, watch this repository's releases.
